## Что нужно сделать
Пользователь задаёт вопрос к аналитической БД обычным языком, LLM строит SQL, система проверяет запрос и возвращает результат.

## Технологии
Python, FastAPI, LLM, PostgreSQL/ClickHouse, Kafka, SQLGlot, Redis, Docker

## Архитектура
NL→SQL service + SQL validation sandbox + query execution + result API

## Паттерны
Facade, Strategy, Adapter, Proxy, Chain of Responsibility
