Python, Kafka, LightGBM, NetworkX, Redis, ClickHouse, FastAPI, Docker

## Архитектура
Streaming transaction graph + rules + graph features + ML scoring

## Паттерны
Strategy, Chain of Responsibility, Repository, Adapter, Observer
