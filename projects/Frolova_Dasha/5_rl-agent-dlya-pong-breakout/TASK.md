## Технологии
Python, Gymnasium, PyTorch, Stable-Baselines3, Pygame, MLflow, Docker

## Архитектура
Environment + trainer + inference + metrics/experiment tracking

## Паттерны
State, Strategy, Observer, Factory, Command
